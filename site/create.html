Create a flow

Build the Discretionary housing payment flow yourself on the demo pages: tell Power Loader what the form collects, show it where each value lives in the other systems, test it, and export it for your team. Allow about twenty minutes.

You don’t need a forms library to make a flow. You make it on the real pages, and it’s saved in Firefox as you go.

With the AI gateway from Level 1, the ✦ buttons do most of the mapping for you, and you check and correct it. Without it, you map each field by clicking. That takes longer, but it’s the same flow.

The idea: start from the form

A flow has at least one form to fill (where the values go) and at least one page to clip (where they come from). Between them is the contract: the list of fields, each defined once with a name and a type, such as a date, an amount of money or an NI number.

You always start with the form, because the form decides what the flow has to collect. Then for each field, you find the page it comes from.

Build it

  1. Create the flow

    In the sidebar, open Flows and press New flow. Fill in Name of the flow (for example “DHP application”) and paste the guidance into Guidance (optional). The new flow already has Form to fill 1 and Page to clip 1.

  2. Choose the form to fill

    Open Form to fill 1. The sidebar asks Which form does this flow fill? In the same tab, go to the Discretionary housing payment form, or paste its address and press Go to it. Then press Use the current form. If Firefox asks, allow Power Loader on {{HOST}}.

  3. Work out what the form collects

    With AI: press ✦ Generate the extraction profile with AI. Check the preview: the form’s boxes and your guidance, with any personal data replaced by placeholders. Then send it. The AI names a field for each box, with its type. Each suggestion is marked Suggested by the AI for you to check.

    By hand: press Make it by hand. Every box on the form is outlined. Type a field’s name in Add a field this form collects (for example “Date of birth”), choose it, then click its box on the page. Repeat for each box.

    Either way, you can correct anything: click a box to change its field, tick Required, and for the reason for the application tick The caseworker types it, because it isn’t on any page.

  4. Test the form

    Press Test on this page. Power Loader checks that every field finds its box. When it says Test passed on this page, go back to the flow with Back to the flow. The fields list now shows what the flow has to gather.

  5. Map the client record

    Open Page to clip 1, go to client record NC-1042 and press Use the current page.

    With AI: press ✦ Generate the extraction profile with AI. The AI gets the page’s layout with every value on it replaced by a placeholder, so it never sees Maria’s details. It returns where each field is.

    By hand: every value Power Loader can read is outlined. Choose a field and press Find it, then click its value on the page. If a value isn’t outlined, use Pick something that isn’t outlined.

    Using a real record is fine: only where values are, not the values themselves, is kept in the flow.

  6. Test it on two records

    Press Test on this page, then open client record NC-2077 and press Test on this record too. A mapping that works on two people’s records doesn’t depend on one person’s details.

  7. Add the other pages

    Back on the flow, press + Add another page to clip twice. Do the same for the rent account and employment and income: use the current page, find the fields the form still needs, and test.

  8. Clear the checks

    The flow is checked every time it changes. Under Checks, each problem says what’s wrong and offers fixes: a field no page gathers yet, a page that hasn’t been tested, a value that might be personal data left in the flow. ✦ Fix with AI asks the AI to find just the fields that are missing. When it says Every page is made and tested, and every field a form needs is gathered, the flow is ready.

  9. Use it, and export it

    Press Start case to try it straight away, just as in Level 2. Then press Export. You get one .flow.json file with the flow and the library files it becomes. Send it to whoever maintains your team’s forms library, or to a colleague who can use Import a flow….

Shortcut: start from a library form

If you’ve connected a library, Flows → Make a flow from a library form copies a form with its fill profile and the page profiles that read its fields. Change it in the flow; the library itself isn’t changed. It’s a quick way to adapt an existing flow to a new system.

What makes a good flow

  • One task per flow. “Apply for a DHP” rather than “everything about housing”.
  • Name fields the way your team talks. The names appear in the case and the fill plan.
  • Test on more than one record, especially one with gaps, such as no phone number or a different household.
  • Keep the guidance short and factual: which page has what, what the caseworker types, what’s required. Never put personal data in it.
