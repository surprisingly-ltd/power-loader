Journey

  • One active case at a time, always started from one or more target forms.
  • Starred forms start a case in one click. Tick several forms for a multi-form case.
  • Recognised pages show a single Clip this page action and report what changed.
  • The sidebar lists every clip. Undo this clip shows what will change, then lets you keep, trim or purge its activity-log entries.
  • On the target form: fill, submit, then Finish case deletes local data after confirmation.

Progress and conflicts

  • Per-form progress counts required fields only.
  • Conflicts sit at the top in red and are left empty when filling, so a guess never reaches a form.
  • Missing fields say which page usually has them, with a link.
  • The ⤢ button opens the whole case as a full page in its own tab. The page replaces the sidebar, and Back to the sidebar returns to it.

Tools

  • Standard runs in the browser only: subset-sum search and gap arithmetic over clipped values.
  • Enhanced ✦ sends the selected values to the organisation's AI gateway after an explicit action. Responses here are simulated.
  • Results can be saved to the case as workings and are included when copying the case.

Full case page

  • Fields lists everything the forms expect, with each source's link. Click a row to open the source, exclude it, or set your own value.
  • Sources shows what each page or document gave the case and whether it was used.
  • Matrix puts fields against sources in one grid.
  • Activity logs every page visit and action. The log is kept without case values after the case ends, for process mining.
  • Activity log (Settings, or “All cases’ log”) lists every case's events. You can search, filter, add notes, remove items and download them as CSV or JSON.

Magic reader

  • Reads a PDF's text layer when it has one. Otherwise it runs OCR on the device (Standard) or sends the page images to the AI gateway (Enhanced).
  • Documents in frames are downloaded directly where possible. Secure viewers that block this fall back to Select a region, which reads from a screenshot of the tab.
  • When even that fails, snip with Win+Shift+S and paste into the reader.
  • Everything is reviewed before it joins the case: confidence, a quote of the source text, and whether it matches, is new or conflicts.

Privacy

  • Every ✦ action shows what will be sent, with personal data replaced by placeholders such as <redacted:nino|ref:q7m.4|format:AA999999A|confidence:99%>.
  • The AI answers with the same placeholders, and Power Loader puts the real values back on this computer.
  • The on-device model loads from your organisation's model server when Hugging Face is blocked.

Library and profiles

  • Settings → Open the library lists every page profile, fill profile and form from the library repo, with versions and history.
  • Make a profile for this page on an unrecognised page, then click values to add them. Make a new version copies a published profile to a draft you can edit and compare.
  • Drafts are used only on this computer, and only after Test and use. Export checks the file and gives JSON that someone adds to the library repo by hand; everyone gets it at their next sync.
