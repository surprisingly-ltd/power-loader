Notes for add-on reviewers

Power Loader {{VERSION}} · {{ID}} · distributed unlisted to organisations through Firefox enterprise policy.

What it does

Caseworkers start a case from one or more forms in their organisation’s forms library. They clip values from approved casework pages, review where sources agree and conflict, and fill target forms with the checked values. All application logic runs inside the extension. The optional AI features go only to the organisation’s own gateway, and only after the user has approved a redaction preview of the exact request.

No remotely hosted code

  • Every script that runs is in the package. There is no eval, new Function or innerHTML in Power Loader’s own code, and the CSP forbids 'unsafe-eval'.
  • The forms library (lib/library-sync.js, lib/library.js) downloads JSON only. It is checked against a manifest with a SHA-256 per file and validated as untrusted input. Profiles are a declarative extraction language, which lib/extract.js interprets with DOM queries. Detection patterns in privacy.json are compiled with new RegExp. Nothing from the library is executed as code.
  • Model weights for the on-device privacy model (Transformers.js plus ONNX Runtime WASM, in privacy/worker.js) are data, not code. By default they come from Hugging Face: openai/privacy-filter, pinned to commit {{MODEL_REVISION}}. The SHA-256 of every file is built into the extension (DEFAULT_MODEL in lib/model-fetch.js), and each download is checked as it streams. A request outside the model server, or for a file with no expected hash, is refused. The user can choose another server with the same files (Privacy tab), and policy can lock the address. Either way the pinned revision and hashes still apply unless policy sets others. Files are fetched with CORS, which Hugging Face allows, so no host permission is needed.
  • Prompts are packaged Markdown files in prompts/.
  • Tesseract runs with workerBlobURL: false, and its worker, core and language data are all loaded from vendor/, never from a CDN.

Content security policy

script-src 'self' 'wasm-unsafe-eval'; object-src 'none'; img-src 'self' data: blob:;
frame-src 'none'; media-src 'none'; style-src 'self' 'unsafe-inline'
  • 'wasm-unsafe-eval' is required to instantiate the packaged WebAssembly: ONNX Runtime for the privacy model, and tesseract.js-core for OCR.
  • img-src data: blob: displays pictures and PDF pages the user drops into the reader, after they are rendered on the computer.

Updates

This add-on is self-distributed (unlisted). Its update_url is {{SITE}}/updates.json, published by GitHub Pages from the public repository. It lists only Mozilla-signed XPIs, each with its SHA-256, served from {{SITE}}/download/. Organisations install it by enterprise policy from {{DOWNLOAD}}. We lint with web-ext lint --self-hosted for this reason.

Data collection

Firefox 140 or newer is required for built-in data consent. The manifest declares website content, personally identifying information, financial/payment information and health information, as case text can contain all of these. Images cannot be sent to AI in this release. The Settings gateway test sends only the fixed text “Reply with OK.”

Power Loader declares its data categories in data_collection_permissions. Case data is stored locally and deleted when the case ends. The only transmissions are to the organisation-configured forms library and AI gateway, and model-file downloads from the model server (Hugging Face by default), which carry no case data. See the privacy policy. Every case-data AI request passes through previewBeforeSend() in lib/ai/boundary.js, and lib/ai/client.js refuses any payload that has not been approved. There is no analytics or telemetry, and no case data is sent to the publisher. If the user chooses our hosted demo library, our hosting service receives ordinary request metadata to serve its fictional files.

Third-party libraries

The PDF/OCR libraries and ONNX WASM/loader are unmodified files from npm releases, copied into vendor/ by tools/vendor.mjs. The same list ships in the package as vendor/SOURCES.tsv. Each checksum can be checked against the linked file:

curl -sL <url> | sha256sum

The linter’s DANGEROUS_EVAL and UNSAFE_VAR_ASSIGNMENT warnings are all inside these library files. None comes from Power Loader’s own code.

Rebuilding from source

The source archive contains the current build inputs, with per-file SHA-256 hashes in SOURCE.json; it excludes local credentials, caches, dependencies and generated files. The build uses open-source tools only:

# Node.js {{NODE}}, pnpm {{PNPM}}, on Linux, macOS or Windows
pnpm install --frozen-lockfile
pnpm build:ext            # runs tools/vendor.mjs, then web-ext build
# output: dist/power-loader-{{VERSION}}.zip, and the packaged tree is extension/

Power Loader’s own code in extension/ is not minified, bundled or transpiled. The build copies the libraries listed above and bundles the unmodified Transformers.js web entry with released ONNX Runtime 1.30.0 using esbuild 0.27.2. The upstream all-in-one bundle embeds a prerelease runtime and is excluded. The exact inputs and generated bundle hash are in vendor/BUNDLE.json. Run pnpm vendor to reproduce it; the generated bundle will not match a CDN copy.

Trying it

The quickest way is the hosted demo: fictional casework pages and a forms library at {{SITE}}/demo/. Try the demo walks through every feature step by step. In short:

  1. Open the sidebar. In Settings, enter the library address {{DEMO_LIBRARY}}, press Connect and allow access to the site.
  2. On the Case tab, tick two forms and start a case.
  3. Open /demo/client-1042.html, press Allow on {{HOST}}, then Clip this page. Clip the rent account (it produces a conflict) and client-2077 (a different person, which shows the identity warning).
  4. Open /demo/dhp.html and press Fill this form. The plan is shown before anything is filled, and Power Loader never submits.

Page and library access is asked for at run time, through the optional host permission, so the demo needs no extra permission in the manifest. The demo pages are static HTML and their forms only move between pages on this site. AI features need an organisation gateway, which the public demo doesn’t have. Without one, the preview still works and nothing is sent.

The same demo runs offline from the source archive with pnpm demo (library address http://localhost:8787/demo/library/). pnpm test runs the unit tests.
