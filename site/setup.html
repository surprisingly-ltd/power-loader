Training · Level 1

Setup

Install the add-on, download the privacy model that runs on your own computer, and connect your organisation’s AI gateway if you have one. It takes about ten minutes, most of it waiting for the model to download.

You need Firefox 140 or newer on a desktop or laptop (Windows, macOS or Linux), and about 1 GB of free space for the privacy model. The AI gateway is optional: everything except the ✦ AI buttons works without it.

1. Install the add-on

Power Loader is signed by Mozilla and distributed from this site rather than the public add-ons store, because organisations deploy it to their own staff.

For a whole organisation (recommended)

Ask IT to add it to Firefox’s enterprise policy. In policies.json, or the matching Group Policy or configuration profile settings:

{
  "policies": {
    "ExtensionSettings": {
      "{{ID}}": {
        "installation_mode": "force_installed",
        "install_url": "{{DOWNLOAD}}"
      }
    }
  }
}

Firefox installs it on next start. Signed releases update themselves from this site. Policy can also set the forms library, the AI gateway and the model server for everyone: see settings by policy below.

On one computer

  1. In Firefox, open the latest signed release.
  2. Firefox asks whether to add Power Loader. Choose Add, then OK.

From source, for development

Clone the repository, run pnpm install and pnpm vendor, then open about:debugging#/runtime/this-firefox, choose Load Temporary Add-on… and select extension/manifest.json. Temporary add-ons are removed when Firefox closes.

2. Open the sidebar

Press the Power Loader button in the toolbar (the striped amber mark). If you can’t see it, open the Extensions menu (the jigsaw piece) and pin it. The sidebar opens on the left. The first time, it opens at Settings with a list of what still needs setting up.

3. Download the privacy model

Before anything goes to an AI, Power Loader finds personal data such as names, addresses, dates of birth and reference numbers, and swaps them for placeholders. Part of that is a small AI model that runs entirely on your computer: OpenAI Privacy Filter, about 920 MB, downloaded once.

  1. Open Settings → On-device privacy model

    It says where the model comes from. By default that’s Hugging Face, at a fixed version ({{MODEL_REVISION}}). Every file is checked against a known SHA-256 hash as it downloads, so a changed file is refused.

  2. Press Download and test the model

    Power Loader downloads the files, starts the model on your graphics card and runs a test scan. When it’s done it says Ready. You can keep working while it downloads.

  3. Check it works

    Open the Privacy tab, choose Check some text, paste a made-up sentence such as “Maria Kowalska of 14 Dock Road, born 3 March 1984, called about her rent” and press Check text. The name and address are highlighted, and the redacted text shows what an AI would receive instead.

If huggingface.co is blocked at work, IT can host the same files on an internal server. Under Privacy → Where the model comes from, choose Another model server and enter its Model server address. The files must be at the same paths as on Hugging Face, and the same hashes are checked.

If it says WebGPU isn’t available, Firefox can’t use this computer’s graphics card for the model. Update Firefox and your graphics drivers, or ask IT. Without the model, Power Loader still redacts what it knows from the case and from the library’s patterns, and policy decides whether AI requests may go ahead.

To free the space later, use Remove the downloaded model in the same place.

4. Connect your AI gateway (optional)

The ✦ buttons use AI to help build flows: to work out what a form collects and where each value is on a page. Power Loader only talks to an AI through an OpenAI-compatible chat completions endpoint that your organisation controls, such as a LiteLLM proxy or a cloud provider’s gateway. You never use a personal AI account.

  1. Get the details from IT

    You need three things: the endpoint address (ending in /v1), a model name (often an alias such as fast), and an API key made for Power Loader alone, ideally with a spending limit and an expiry date.

  2. Open Settings → ✦ Remote AI

    Fill in Endpoint address (including /v1), Model name and API key. Tick Remember the key in this browser if you don’t want to enter it again after Firefox restarts. Otherwise it lasts for this session.

  3. Read and tick the confirmation

    It says what is sent to the remote AI, and asks you to confirm you’ve checked that your organisation allows it.

  4. Press Turn on the remote AI

    Firefox asks whether Power Loader may contact the gateway’s site. Choose Allow.

  5. Press Test the connection

    This sends only the fixed text “Reply with OK.” It should say Gateway reachable and name the model. If it fails, the message says what to check: the address, the key, or the network path to the gateway.

What the AI sees. Every ✦ request opens a preview first. Personal data is replaced by placeholders such as <redacted:person_name|ref:…>, and you can switch any item between redacted and sent as written. Nothing is sent until you approve the preview. When the answer comes back, the real values are put back on your computer.

5. Connect a forms library (if your team has one)

A forms library is where a team keeps its approved flows: forms, fields and page profiles, each checked against a hash. Under Settings → Forms library, enter the Library address and press Connect. Level 2 does this with our demo library. You don’t need a library to build your own flows.

6. Check it’s ready

In Settings, choose Check Power Loader is ready. It checks the policy, the library, the gateway and its key, WebGPU, the privacy model, free storage and permissions, and says what to fix. Copy diagnostics copies a report with no case data in it, for IT or for an issue on GitHub.

Settings by policy, for IT

Everything above can be set for every computer through Firefox policy, under 3rdparty → Extensions → {{ID}}. Anything set by policy is locked in the sidebar and shows 🔒 Set by your organisation. Firefox reads policy when it starts, so changes need a restart.

{
  "policies": {
    "3rdparty": {
      "Extensions": {
        "{{ID}}": {
          "library": { "baseUrl": "https://git.example.org/casework/flows/-/raw/{ref}/", "branch": "main" },
          "gateway": { "baseUrl": "https://ai-gateway.example.org/v1", "model": "fast" },
          "privacyModel": { "baseUrl": "https://models.example.org/huggingface/" },
          "activityLog": { "retentionDays": 90 }
        }
      }
    }
  }
}

Each person still enters the gateway API key themselves. The full list of policy settings is in the README.
